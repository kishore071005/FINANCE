# 13 — Testing Strategy

The implementation must include tests at appropriate levels.

## Unit Tests

Test isolated business calculations and validation.

## Integration Tests

Test API + business/service + database behavior where practical.

## End-to-End Tests

Test important user workflows through the actual application.

## Required Test Cases

See the dedicated files under each module (`modules/<name>/test-cases.md`) and the global list of required test cases that apply across modules.
