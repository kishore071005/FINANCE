# 16 — AI Agent Workflow

The AI agent must follow this workflow.

## Phase 1 — Inspect

Before coding:

1. Inspect repository structure.
2. Inspect package files.
3. Inspect existing documentation.
4. Inspect existing environment configuration.
5. Inspect existing frontend architecture.
6. Inspect existing backend architecture.
7. Inspect existing database integration.
8. Inspect existing tests.

**Do not immediately start coding.**

## Phase 2 — Plan

Produce an implementation plan covering:

- Modules
- Components
- APIs
- Data models
- Data flow
- Business logic
- Tests
- Dependencies

Identify ambiguities before implementation.

## Phase 3 — Implement

Implement in small logical increments.

After each major module:

- Run relevant tests.
- Check type / build errors.
- Review the changed files.

## Phase 4 — Validate

Run:

- Unit tests
- Integration tests
- E2E tests where available
- Frontend production build
- Backend validation
- Lint / type checks where configured

## Phase 5 — Review

Compare the implementation against this harness.

Explicitly verify:

- Requirements coverage
- Tech-stack compliance
- Business-rule correctness
- Security
- Error handling
- Test coverage
- No unnecessary dependencies
- No invented business requirements

## Phase 6 — Report

At completion provide:

1. What was implemented.
2. Files changed.
3. Tests executed.
4. Test results.
5. Build results.
6. Known limitations.
7. Requirements that still require human clarification.
