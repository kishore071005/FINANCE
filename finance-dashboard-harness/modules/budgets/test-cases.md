# Budget Module — Required Test Cases

## Test Case 5 — Budget Remaining

**Input**
```
Budget = 100000
Actual Spending = 75000
```

**Expected**
```
Remaining Budget = 25000
```

## Test Case 6 — Budget Overrun

**Input**
```
Budget = 100000
Actual Spending = 120000
```

**Expected**
```
Remaining Budget = -20000
```

The UI / report should clearly indicate that the department exceeded its budget.
