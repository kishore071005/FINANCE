# Salary Module — Required Test Cases

## Test Case 7 — Salary Summary

**Input**
```
Employee A = 50000
Employee B = 40000
Employee C = 60000
```

**Expected**
```
Total Monthly Salary Cost = 150000
```

## Test Case 8 — Department Salary Summary

**Input**
```
Engineering:
  Employee A = 50000
  Employee B = 60000

Marketing:
  Employee C = 40000
```

**Expected**
```
Engineering = 110000
Marketing = 40000
Total = 150000
```
